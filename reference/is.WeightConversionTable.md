# Check if argument is WeightConversionTable

Checks if argument conforms to specification for
[`WeightConversionTable`](WeightConversionTable.md)

## Usage

``` r
is.WeightConversionTable(WeightConversionTable)
```

## Arguments

- WeightConversionTable:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`WeightConversionTable`](WeightConversionTable.md)
