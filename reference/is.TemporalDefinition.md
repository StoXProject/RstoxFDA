# Check if argument is TemporalDefinition

Checks if argument conforms to specification for
[`TemporalDefinition`](TemporalDefinition.md)

## Usage

``` r
is.TemporalDefinition(TemporalDefinition)
```

## Arguments

- TemporalDefinition:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`TemporalDefinition`](TemporalDefinition.md)
