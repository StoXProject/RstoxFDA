# Checks if argument is [`Translation`](https://rdrr.io/pkg/RstoxData/man/Translation.html)

Checks if argument conforms to specification for
[`Translation`](https://rdrr.io/pkg/RstoxData/man/Translation.html)

## Usage

``` r
is.Translation(Translation)
```

## Arguments

- Translation:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`Translation`](https://rdrr.io/pkg/RstoxData/man/Translation.html)
