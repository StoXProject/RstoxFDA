# Check if argument is LengthConversionTable

Checks if argument conforms to specification for
[`LengthConversionTable`](LengthConversionTable.md)

## Usage

``` r
is.LengthConversionTable(LengthConversionTable)
```

## Arguments

- LengthConversionTable:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`LengthConversionTable`](LengthConversionTable.md)
