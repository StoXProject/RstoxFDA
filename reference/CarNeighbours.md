# Area Neighbour Definition (CarNeighbours)

Table
([`data.table`](https://rdrr.io/pkg/data.table/man/data.table.html))
defining neighbours for a CAR-variable (Conditional autoregressive
variable).

## Details

- CarValue:

  Values for a variable used as CAR-variable

- Neighbours:

  Comma-separated list of neighbours

The table is symmetric, so that if b is a neighbour of a. a is also a
neighbour of b.
