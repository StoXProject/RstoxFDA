# Area Code Positions (AreaPosition)

Table
([`data.table`](https://rdrr.io/pkg/data.table/man/data.table.html))
defining a position for area codes.

## Details

- Area:

  Area code. (key)

- Location:

  optional subdivision of 'Area'

- Latitude:

  WGS84 Latitude, decimal degrees

- Longitude:

  WGS84 Longitude, decimal degrees

If location is provided, the case for missing location is also encoded.
