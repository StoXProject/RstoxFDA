# Check if argument is ReportFdaSamplingData

Checks if argument conforms to specification for
[`ReportFdaSamplingData`](ReportFdaSamplingData.md)

## Usage

``` r
is.ReportFdaSamplingData(ReportFdaSamplingData)
```

## Arguments

- ReportFdaSamplingData:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`ReportFdaSamplingData`](ReportFdaSamplingData.md)
