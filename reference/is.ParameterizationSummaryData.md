# Checks if argument is [`ParameterizationSummaryData`](ParameterizationSummaryData.md)

Checks if argument conforms to specification for
[`ParameterizationSummaryData`](ParameterizationSummaryData.md)

## Usage

``` r
is.ParameterizationSummaryData(ParameterizationSummaryData)
```

## Arguments

- ParameterizationSummaryData:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`ParameterizationSummaryData`](ParameterizationSummaryData.md)
