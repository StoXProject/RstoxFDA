# Check if argument is RecaParameterData

Checks if argument conforms to specification for
[`RecaParameterData`](RecaParameterData.md)

## Usage

``` r
is.RecaParameterData(RecaParameterData)
```

## Arguments

- RecaParameterData:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`RecaParameterData`](RecaParameterData.md)
