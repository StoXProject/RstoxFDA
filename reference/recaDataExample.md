# Example data for Reca

Example is produced by [`prepRECA`](prepRECA.md) and is suited for input
to [`runRECA`](runRECA.md)

## Usage

``` r
data(recaDataExample)
```

## Format

see [`prepRECA`](prepRECA.md).

## Examples

``` r
data(recaDataExample)
if (FALSE) recaResult <- RunRecaEstimate(recaDataExample, 500, 5000) # \dontrun{}
```
