# Age Error Matrix (AgeErrorMatrix)

Table
([`data.table`](https://rdrr.io/pkg/data.table/man/data.table.html))
defining probabilities of misreading age.

## Details

- columns 1..n:

  numeric() \[0,1\]. Probability of reading read age, given that true
  age is as column name.

- ReadAge:

  The read age.

Columns sum to 1.
