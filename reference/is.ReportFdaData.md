# Checks if argument is [`ReportFdaData`](ReportFdaData.md)

Checks if argument conforms to specification for
[`ReportFdaData`](ReportFdaData.md)

## Usage

``` r
is.ReportFdaData(ReportFdaData)
```

## Arguments

- ReportFdaData:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`ReportFdaData`](ReportFdaData.md)
