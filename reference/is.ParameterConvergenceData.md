# Checks if argument is [`ParameterConvergenceData`](ParameterConvergenceData.md)

Checks if argument conforms to specification for
[`ParameterConvergenceData`](ParameterConvergenceData.md)

## Usage

``` r
is.ParameterConvergenceData(ParameterConvergenceData)
```

## Arguments

- ParameterConvergenceData:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`ParameterConvergenceData`](ParameterConvergenceData.md)
