# Check if argument is StockSplittingParameters

Checks if argument conforms to specification for
[`StockSplittingParameters`](StockSplittingParameters.md)

## Usage

``` r
is.StockSplittingParameters(StockSplittingParameters)
```

## Arguments

- StockSplittingParameters:

  argument to be checked for data conformity

## Value

logical, TRUE if argument conforms to specification for
[`StockSplittingParameters`](StockSplittingParameters.md)
